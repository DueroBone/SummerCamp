# Welcome to coding camp!

## Downloads
Software installs are at the [wpilib docs](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/frc-game-tools.html#download-game-tools)

Download the *FRC Game Tools* from NI, which include the Driver Station, Robot Simulator, and Field Simulator. These tools are essential for testing your robot code without needing to be on the field.

Next, download *WPILib* from their github page. It includes the software in which you write code and all of the hidden software that runs the robot.
